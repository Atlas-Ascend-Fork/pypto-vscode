# 锁定计算链路

## 功能说明

支持锁定当前通路并高亮显示，便于用户仅查看当前通路的信息。

## 前提条件

执行PyPTO程序，生成计算图文件。

## 操作步骤

1. 打开计算图文件，下面提供两种方式，用户任选其一即可：
    - 在Visual Studio Code侧边栏，单击![插件图标](../figures/zh-cn_image_0000002491082472.png)图标，打开PyPTO Toolkit，在运行结果界面打开计算图文件\(此种方式仅支持打开文件命名以After开头的图\)。
    - 在Visual Studio Code工作区，右键单击计算图文件，在弹出的菜单中选择“PyPTO Toolkit：打开文件”。

2. 右键单击计算图中的节点，或鼠标悬浮到节点上并通过快捷键（Ctrl+L）选择“锁定通路并高亮”。

    ![锁定前](../figures/zh-cn_image_0000002502414338.png)

    当前链路整体高亮锁定，其他节点置灰。通过快捷键（ESC）可退出锁定。

    ![锁定后](../figures/zh-cn_image_0000002480215508.png)

3. 右键单击计算图中的节点，或鼠标悬浮到节点上并通过快捷键（Ctrl+H）选择“只看当前通路”。

    当前链路整体高亮锁定，其他节点消失。通过快捷键（ESC）可退出锁定。

    ![只看后](../figures/zh-cn_image_0000002512495361.png)

4. 右键单击计算图中的节点，或鼠标悬浮到节点上选择“在新标签查看当前通路”。

    在打开新标签页，仅重新排列当前通路的节点，且处于非锁定状态。您可以继续使用右键菜单功能，例如继续锁定或者查看更小通路

    ![查看前](../figures/zh-cn_image_0000002512495362.png)

    ![查看后](../figures/zh-cn_image_0000002512495363.png)

5. 右键单击计算图中的节点，或鼠标悬浮到节点上选择“上一个”或者“下一个”。

    将选中节点切换成上一个节点或者下一个节点

    ![切换前](../figures/zh-cn_image_0000002512495364.png)
    ![切换后](../figures/zh-cn_image_0000002512495365.png)
