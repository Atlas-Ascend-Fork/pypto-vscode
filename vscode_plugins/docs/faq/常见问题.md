# 常见问题

## 问题1：布局过程中，出现堆栈异常报错

解决方案：安装java-elk-extension插件，可以加速布局的同时解决堆栈溢出报错问题

## 问题2：计算图开启时卡在数据转换或者布局中很长时间

解决方案：关闭计算图界面清空缓存后尝试重启，还是卡住可以开启“帮助”=>"切换开发人员工具"=>"console"界面查看报错内容进行具体定位

## 问题3：切换主题以后节点颜色过深或者过浅，看不清

解决方案：部分颜色无法实时响应主题，切换主题后需要重新开启相关页面

## 问题4：首次安装插件后开启计算图无反应

解决方案：一般重启IDE可以解决，并且保证没有同时安装不同版本或存在同指令插件，如：Ascend C++ Toolkit

## 问题5：已打开的计算图，再修改文件内容后，如果再打开，数据库没有更新

解决方案：按快捷键F1或者Ctrl+Shift+P打开命令搜索栏，输入PyPTO.comGraph:Delete Cache DB File,选择对应命令，清除缓存数据库，再尝试重新打开计算图（其他异常问题也可以先尝试清除缓存再试试）

## 问题6：打开计算图出现数据文件异常的报错提示

解决方案：根据报错点修复之后再重新打开计算图。

- 读json文件报错：节点opmagic重复
- 数据库未查询到数据：通常是没有对应entryhash的function.hash
- 无法创建输出节点：对应funchash、magic的对应属性tensor.magic不存在
- 无法创建tensor节点：对应funchash、magic的对应属性tensor中rawtensor为0节点

## 问题7： 健康报告有一些空数据

解决方案：目前健康报告部分信息来自上板PMU数据，如果没有采集这部分数据，相关信息会显示为 / 。

## 问题8：如何查看一段节点占用的总耗时

解决方案： 

- 使用度量模式： 点击泳道图右上角的Measure按钮。在时间轴中拖动时间起止坐标。
- 使用手动测距： 按住ALT并鼠标左键点击起始节点和终止节点。
