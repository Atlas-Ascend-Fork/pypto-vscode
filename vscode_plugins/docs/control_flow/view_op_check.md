# 查看Op粒度精度对比报告

## 功能说明

打开OpCheck页面后，若文件包含Op粒度精度对比数据，可在数据导入成功后查看Op粒度精度对比报告。

## 前提条件

文件包含Op粒度精度对比数据。

## 操作步骤

### 步骤一：打开OpCheck页面

在运行结果界面中，单击`OP Check`按钮，打开OpCheck页面。程序将自动导入Op粒度精度对比数据，导入成功后，左侧compareList区域会显示可解析的Op粒度精度对比数据列表。

**图 1**  `OP Check`按钮位置
![](../figures/opcheck-compare-list.gif)

### 步骤二：解析数据并打开Diff视图

在compareList中单击需要查看的数据项：

- **未解析的数据项**：点击后弹出解析对话框。单击`开始解析`按钮启动解析过程，解析完成后，右侧将显示Diff视图并更新数据项状态。初始未解析的数据项无状态标识，解析完成后状态更新为`PASS`或`x FAIL`（x表示差异数量，例如：有5个差异时显示为`5 FAIL`）。
- **已解析的数据项**：点击后直接在右侧显示Diff视图。

**图 2**  Diff视图展示效果
![](../figures/opcheck-compare-file.gif)

### 步骤三：查看Diff视图

Diff视图提供以下功能：

- 支持精准搜索Op名称
- 支持筛选`仅Pass`或`仅Fail`的数据项
- 单击数据项展开按钮，可查看详细数据
- 单击选中数据项，可打开精度结果详情

**图 3**  Diff视图操作界面
![](../figures/opcheck-compare-fail.gif)

### 步骤四：查看精度结果

精度结果页面提供以下功能：

- 支持点击跳转到对应的计算图
- 通过Tab页切换`概览`和`精度异常详细对比`视图

**图 4**  精度结果详情页面
![](../figures/opcheck-compare-fail-report.gif)
