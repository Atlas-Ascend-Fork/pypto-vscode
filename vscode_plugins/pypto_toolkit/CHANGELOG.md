# PyPTO Toolkit 插件版本变更说明

## [0.1.11] - 2025.09.29

### Added

- 计算图新增对比能力，支持文件打开和自动查找对比图
- 计算图节点详情，会展示offset和shape的具体映射值
- 泳道图优化操作性能，大数据下缩放速度显著提升
- 泳道图添加时钟周期维度度量数据

### Fixed

- 计算图修复切换布局中的搜索范围不正确
- 泳道图修复放大到一定尺寸卡死的问题

## [0.1.10] - 2025.09.18

### Added

- 插件正式升级为 PyPTO Toolkit, 界面和图标全面升级
- 泳道图增加时间观测线
- 计算图增加图层控制能力（增加仅展示 OP 能力和上下布局能力）
- 计算图增加锁定指定通路和只查看指定通路的能力

## [0.1.9] - 2025.09.04

### Fixed

- 泳道图手动测距交互方式优化
- 修复计算图和泳道图的部分UI细节问题

## [0.1.8] - 2025.09.02

### Added

- 泳道图支持时间度量模式
- 泳道图适配明亮主题

### Fixed

- 计算图和泳道图修复部分细节问题
- 泳道图跳转计算图默认打开当前目录的program.json

## [0.1.7] - 2025.8.30

## Added

- 计算图泳道图入口合一
- 计算图健康报告支持节点跳转
- 计算图增加整图搜索能力
- 泳道图增加跳转dump tensor能力
- 插件增加旧版本检测

## Fixed

- 计算图修复选中节点国立视图后丢失关联关系的问题

## [0.1.6] - 2025.8.27

- 计算图支持自定义节点显示字段
- 计算图支持导航栏、模糊搜索、优化样式
- 计算图适配明亮主题
- 泳道图支持测距、搜索task
- 泳道图 rootHash leafHash 支持跳转至计算图
- 泳道图连线层级支持配置

## [0.1.2] - 2025.08.20

- 增加计算图泳道基础功能
