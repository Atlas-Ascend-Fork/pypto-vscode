# PyPTO Toolkit 插件版本变更说明

## [2.0.2] - 2026.01.16

### Added

- 计算图增加对布局加速插件java-elk-extension布局的支持，性能可提升50%
- 泳道图支持图片导出、链路锁定、按rootHash和leafHash搜索
- 三栏模式下计算图下钻后支持返回原图
- 新手引导支持返回上一步、开放三栏视图
- 新增PyPTO源码工程运行配置可视化

## [2.0.1] - 2026.01.08

### Added

- 优化新手引导在运行python文件时的结果输出

## [2.0.0] - 2025.12.31

### Added

- 新增新手引导功能
- 新增针对pypto.jit装饰器的调试模式便捷开关功能
- 计算图搜索模式支持整图搜索
- 三栏模式支持动态选择文件，支持在泳道图选中和代码点击时计算图自动下钻

## [1.1.0] - 2025.12.18

### Added

- 计算图差异对比支持查看节点详情
- 计算图支持通过解析日志，获取错误节点信息并在图中高亮展示
- 泳道图支持打开1GB内的文件
- 泳道图报错提示优化

## [1.0.3] - 2025.12.12

### Added

- 三栏模式泳道图默认按语义标签染色，支持锁定时计算图自动下钻
- 计算图支持右键主动开启局部搜索渲染
- 计算图报错提示优化，增加更多阻塞问题提示
- 泳道图新增快捷键说明页面
- 泳道图支持使用触控板横向移动画布
- 支持一键关闭所有插件打开的页面

## [1.0.2] - 2025.11.29

### Added

- 三栏模式支持布局位置和尺寸调整、全屏查看
- 三栏模式高亮动画优化
- 计算图差异对比支持上下布局
- 泳道图节点依赖支持从 dyn_topo.txt 中解析
- 为泳道图添加缓存机制，重复打开时渲染效率提升 20%~50%

## [1.0.1] - 2025.11.13

### Added

- 新增基于语义标签的三栏联动视图

### Fixed

- 泳道图修复高分辨率屏幕测距不显示的问题
- 计算图修复 root 文件中的 funcname not found 问题

## [1.0.0] - 2025.11.06

### Added
- 新增workflow控制流能力
- 计算图在节点缩小后支持悬浮展示全量信息
- 泳道图鼠标悬停依赖线支持展示tensor列表

### Fixed
- 泳道图修复度量模式范围不与画布同步问题


## [0.1.12] - 2025.10.20

### Added

- 泳道图新增各种统计维度信息展示（含PMU信息）能力
- 泳道图增加自由框选能力和针对框选范围内信息统计展示能力
- 计算图开启大数据文件时支持局部搜索和展示
- 计算图支持显示打开的图类型

## [0.1.11] - 2025.09.29

### Added

- 计算图新增对比能力，支持文件打开和自动查找对比图
- 计算图节点详情，会展示offset和shape的具体映射值
- 泳道图优化操作性能，大数据下缩放速度显著提升
- 泳道图添加时钟周期维度度量数据

### Fixed

- 计算图修复切换布局中的搜索范围不正确
- 泳道图修复放大到一定尺寸卡死的问题

## [0.1.10] - 2025.09.18

### Added

- 插件正式升级为 PyPTO Toolkit, 界面和图标全面升级
- 泳道图增加时间观测线
- 计算图增加图层控制能力（增加仅展示 OP 能力和上下布局能力）
- 计算图增加锁定指定通路和只查看指定通路的能力

## [0.1.9] - 2025.09.04

### Fixed

- 泳道图手动测距交互方式优化
- 修复计算图和泳道图的部分UI细节问题

## [0.1.8] - 2025.09.02

### Added

- 泳道图支持时间度量模式
- 泳道图适配明亮主题

### Fixed

- 计算图和泳道图修复部分细节问题
- 泳道图跳转计算图默认打开当前目录的program.json

## [0.1.7] - 2025.8.30

## Added

- 计算图泳道图入口合一
- 计算图健康报告支持节点跳转
- 计算图增加整图搜索能力
- 泳道图增加跳转dump tensor能力
- 插件增加旧版本检测

## Fixed

- 计算图修复选中节点国立视图后丢失关联关系的问题

## [0.1.6] - 2025.8.27

- 计算图支持自定义节点显示字段
- 计算图支持导航栏、模糊搜索、优化样式
- 计算图适配明亮主题
- 泳道图支持测距、搜索task
- 泳道图 rootHash leafHash 支持跳转至计算图
- 泳道图连线层级支持配置

## [0.1.2] - 2025.08.20

- 增加计算图泳道基础功能
