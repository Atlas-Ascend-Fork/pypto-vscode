#  内存可视化视图

##  功能说明

根据内存trace文件，将其转换成内存可视化页面

##  前提条件

计算图文件和内存trace文件在同一目录

##  操作步骤

1. 在Visual Studio Code工作区，右键单击计算图文件或者内存trace文件，例如\*\_OoO_Memory_Trace.json，在弹出的菜单中选择“PyPTO Toolkit：打开文件”。

- 如果打开是计算图文件且目录下有对应内存可视化文件，计算图界面右侧就会有内存可视化视图的按钮;如果没有对应可视化文件则不会出现按钮。

- 如果打开的内存trace文件且目录下有对应计算图文件，则会直接打开计算图+内存可视化界面；如果没有计算图文件则不允许展示内存可视化界面。

![打开内存可视化](../figures/memory-usage1.gif)

2. 打开内存可视化界面，最下方是事件条，按发生时间点clock划分。点击对应clock可以展示对应时间点的所有事件列表。

![事件条](../figures/memory-usage2.gif)

3. 事件列表允许事件按列表播放或者单个事件播放。单击事件名可以查看事件详情。

![事件播放](../figures/memory-usage3.gif)
