# 联动视图

## 功能说明

联动视图是指在一个页面中同时展示 Py 源码、CCE 源码、计算图和泳道图，这四者以计算图为中枢相互关联。用户在任一视图中悬浮或单击，其余视图会联动高亮显示对应内容，从而帮助开发者快速理解从 PyPTO 代码实现，到计算图表达，到 CCE 代码实现，再到泳道图最终性能表现的整个过程。

联动视图支持两种联动方式：

- **悬浮联动**：鼠标悬浮在任一视图的可关联对象上（Py 代码行、CCE 代码行、计算图节点、泳道图 Task），其余视图实时高亮显示对应内容，鼠标移开后自动恢复。
- **锁定联动**：单击任一视图中的可关联对象，联动关系被持久锁定，便于持续观察某一目标。此时鼠标悬浮不再改变联动状态。

若插件未在运行结果目录中识别到 CCE 源码目录，联动视图以三栏模式展示（Py 源码、计算图、泳道图）。

## 联动机制

计算图是联动视图的中枢，其余三个视图分别通过不同的关联键与计算图建立映射，如下图所示。

## 前提条件

- 执行PyPTO程序，生成计算图和泳道图文件。
- （可选）在PyPTO程序代码中，使用 pypto.set\_semantic\_label 接口设置自定义语义标签，用于在联动时按语义粒度圈定关联范围。

    ```python
    pypto.set_semantic_label("softmax")
    softmax_out = pypto.softmax(tile_logits_fp32, -1)
    ```

    未设置语义标签时，联动功能仍可正常使用：各视图通过文件行号、hash+opMagic 和子图 hash 关联；Py 源码和 CCE 源码界面不显示语义标签色条和范围框，计算图和泳道图也不按语义标签圈选关联节点。

## 操作步骤

1. 在 VSCode 工作区，右键单击 PyPTO 代码文件，例如sum\_lstm.py，在弹出的菜单中选择“PyPTO Toolkit：开启联动模式”。

    工具会自动查找当前工作区下的“output/output\_时间戳”目录，识别最新时间戳目录，并从中读取计算图“program.json”、泳道图文件“merged\_swimlane.json”和 CCE 源码目录“kernel\_aicore”，同时结合代码文件，共同打开联动视图。

    如果上述查找没有找到目标文件，则提示用户选择运行结果或手动选择文件。

2. 联动视图展示效果如下所示

    ![](../figures/four_column_overview.png)

    界面以 2×2 四宫格布局同时展示四个视图，每个视图支持拖拽调整分栏比例、拖拽交换位置和全屏查看：

    - **Py 源码**（左上）：只读展示 PyPTO 代码，左侧通过色块标记划分语义标签范围。顶部下拉可以切换计算图中引用的 Py 文件。
    - **CCE 源码**（左下）：只读展示编译产出的 CCE 代码。顶部下拉可以切换`kernel_aicore`目录下的 CCE 源码文件。
    - **计算图**（右上）：顶部下拉可以切换 program.json 下的子图。关于计算图的详细用法请参见[计算图](../computation_graph/view_computation_graph.md)。
    - **泳道图**（右下）：展示 Task 的执行耗时和依赖关系。关于泳道图的详细用法请参见[泳道图](../swimlane_graph/swim_category/basic_swim.md)。

3. 悬浮联动

    将鼠标悬浮在任一视图的可关联对象上，其余视图会实时联动高亮，效果如下所示。

    ![](../figures/four_column_hover.png)

    - 在 Py 源码界面，高亮显示当前代码行（整行蓝条）和同一语义标签的代码段（渐变描边框）。
    - 在 CCE 源码界面，高亮显示当前算子对应的产码行和同一语义标签的代码段。
    - 在计算图界面，高亮显示当前算子节点，框选同一语义标签的其余节点，其余部分置灰显示。
    - 在泳道图界面，圈选同一语义标签的 Task 节点并高亮当前算子所在的 Task，其余部分置灰显示。

    悬浮联动时，各视图会自动滚动定位到关联内容。如果当前视图没有可关联内容（例如悬浮的计算图节点所在子图没有 CCE 源码），则该视图显示“暂无关联对象”。

4. 锁定联动

    在任一视图中单击可关联对象（Py 代码行、CCE 代码行、计算图节点、泳道图 Task），即可锁定联动关系，效果如下所示。

    ![](../figures/four_column_lock.png)

    - 锁定后，鼠标悬浮不再改变联动状态。
    - 当锁定的目标在多个视图中存在多个关联 op（例如一行 Py 代码对应多个计算图 op）时，计算图小地图上方会出现“上一个/下一个相关节点”按钮，在相关 op 之间循环切换，各视图同步更新。

    在任一视图单击解锁按钮，即可退出锁定模式。单击其他可关联对象，则切换锁定目标。

5. 文件与子图联动

    - 计算图切换子图时，CCE 源码自动切换到该子图对应的 CCE 文件；在 CCE 源码界面切换文件时，计算图也会自动切换到对应的子图。两者双向绑定。
    - 当锁定的目标 op 不在当前子图时，计算图会自动下钻并定位到目标子图。
    - 在 Py 源码界面切换文件时，如果锁定目标位于新文件中，锁定关系保持不变。
