# Project Documentation

## Introduction

This directory provides source files for the [PyPTO Toolkit Documentation Center](https://pypto-tools.gitcode.com), including environment deployment, programming guides, API references, and so on.

## Contribution

Contributions to the documentation are welcome. For details, refer to the [Document Contribution Guide](../docs/CONTRIBUTION_DOC.md). Ensure that you follow the documentation writing specifications and submit according to the process rules. After approval, the content will appear in the docs directory of this project and on the Documentation Center website. If you have any comments or suggestions about the documentation, submit them in Issues.

## Documentation Build

PyPTO Toolkit documentation is generated by Sphinx. When a documentation PR is merged, the documentation build is triggered automatically. Local builds are also supported. Install the required modules before building the documentation locally. The following are the specific steps.

1. Download the PyPTO repository code.

   ```bash
   git clone https://gitcode.com/cann/pypto-tools.git
   ```

2. Enter the docs directory and install the dependencies specified in `requirements.txt`.

   ```bash
   cd docs
   pip install -r requirements.txt
   ```

3. Run the following command in the docs directory to build the documentation.

   ```bash
   make html
   ```

4. After the build is complete, a `_build/html` directory is created. Run the following command to start an HTTP server to serve the documentation.

   ```bash
   cd _build/html
   python3 -m http.server 8000
   ```

   The default port is 8000. You can also specify a different port.

5. Access `http://localhost:8000` in a browser to view the documentation.
